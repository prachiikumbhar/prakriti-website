# prakriti-website
This is a website based on our ancient ayurveda which will help the user to know its "tridosha" according to ayurvedic culture such as pitta , vatta , kapha .
It provides the user remedies based on those dosha and the dosha will be identified based on a questionaire which is based on the physical and the mental health of a person . 
The website also comprises of a graph and a chatbot for any reqired information .
